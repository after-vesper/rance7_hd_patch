ffmpeg
======

bin\ffmpeg.exe is the unmodified static Windows binary bundled in the
imageio-ffmpeg 0.5.1 wheel (ffmpeg version 4.2.2, win64). It is used at
install time only, to decode the original OP/ED movies and re-encode the
HD versions (MPEG-1 video + MP2 audio, same format as the originals).

Downloaded via:

    pip download imageio-ffmpeg==0.5.1
    (binary: imageio_ffmpeg/binaries/ffmpeg-win64-v4.2.2.exe)

FFmpeg is free software licensed under the GNU General Public License
version 3 or later for this build (compiled with --enable-gpl). Its
configuration string is embedded in the binary and can be shown with:

    bin\ffmpeg.exe -version

Source code for the exact binary distributed here:

    https://github.com/imageio/imageio-ffmpeg  (packaging)
    https://ffmpeg.org/download.html            (upstream source, 4.2.2)
