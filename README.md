# 戦国ランス HD パッチ

Steam 版 **戦国ランス (Sengoku Rance / Rance 7)** の画面を、固定の 800×600 から **1600×1200** へ高解像度化するパッチです。ゲームの描画座標・レイアウトを2倍化し、約7,000枚の画像素材を AI アップスケールしたものに差し替えます。

> **⚠️ これは非公式のファンメイドパッチです。アリスソフトおよび発売元とは一切関係ありません。**
> **本パッチの使用はすべて自己責任でお願いします。導入によって生じたいかなる損害・不具合についても作者は責任を負いません。**

## 機能

- **論理解像度 1600×1200** — `Rance7.ain` 内の座標・レイアウト定数を全面的に2倍化(実行ファイルは一切変更しません)
- **HD アセット** — CG・立ち絵・UI・戦闘画面・マップ・CG閲覧モード等の画像を AI アップスケール
- **色精度の保持** — 領地選択マスクやラベルタグ等、色判定が絡む素材はピクセル完全一致のニアレスト2倍化で処理
- **バリアント自動検出** — 適用済みパッチ構成を自動判別して対応する素材セットを選択
- **安全設計** — 書き換え前にタイムスタンプ付きバックアップを作成。失敗時は元ファイルを保持

## 対応環境

以下のいずれの状態でもインストール可能です(適用順を問いません):

- バニラ(Steam 版そのまま)
- JP パッチ適用済み
- その他の非公式パッチ適用済みの構成も、AIN の変更箇所が重ならない限り自動判別されます

> **他パッチとの併用ルール**: 他のパッチは HD パッチより先に当ててください。HD 適用後に他パッチを当てて表示が崩れた場合は、`Install.ps1` を再実行すれば修復されます(再実行は安全です)。

## インストール

1. リリースの ZIP を展開し、`installer` フォルダを開く
2. `Install.cmd` をダブルクリック — Steam のゲームフォルダを自動検出します
3. ゲームフォルダが `Program Files` 配下にある場合は、管理者権限の確認(UAC)が出ます

Steam 以外でインストールしている場合は、パスの入力を求められます。PowerShell から `-GameDir` で直接指定することもできます:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File Install.ps1 -GameDir "D:\Games\SengokuRance"
```

> ゲームを起動したままだとインストールは拒否されます。事前にゲームを終了してください。

### 変更されるファイル

- `Rance7.ain` — 座標・レイアウト定数の2倍化(アンカーベースの書き換え)
- `Rance7GM.ald` / `Rance7GA.ald` — HD 画像素材への差し替え(アーカイブ再構築)
- `AliceLogo3.alk` / `DLL\AliceLogo3.dll` — 起動ロゴ演出の HD 化
- `System40.ini` — `ViewWidth` / `ViewHeight` を 1600×1200 に設定

いずれも書き換え前に `backup\hd_<日時>\` へ元ファイルが保存されます。

## アンインストール

`Uninstall.cmd` をダブルクリックし、復元するバックアップを選択してください(既定は最新)。

最新のバックアップから `Rance7.ain`・`System40.ini`・`Rance7*.ald`・起動ロゴ関連ファイルを復元します。セーブデータには触れません。
復元がすべて検証できた場合、使用したバックアップフォルダは自動で削除されます(他のバックアップは残ります)。

## 注意事項

- **対象は日本語版の Steam 版**です。
- インストールには数 GB の空き容量が必要です(アーカイブ再構築のため一時的に元ファイル+新ファイルが並存します)。
- インストーラはゲーム実行ファイル(`Rance7.exe`)を一切変更しません。
- アンチウイルスソフトがスクリプトや同梱ツールを誤検知する場合があります。その際は除外設定を行ってください。
- **本パッチの使用はすべて自己責任でお願いします。** 導入によって生じた問題(セーブデータの破損・ゲームの動作不良などを含む)について、作者は一切の責任を負いません。導入前にセーブデータのバックアップを推奨します。

## リポジトリ構成(開発者向け)

```
installer/   インストーラ本体 (PowerShell + C#)
  HdPatch.cs     AIN/ALD パッチエンジン (Add-Type でコンパイル、外部依存なし)
  Install.ps1    インストール本体 (バリアント自動検出・バックアップ・検証)
  Uninstall.ps1  バックアップからの復元
  data/          変換済み HD アセット (配布物に同梱、リポジトリには含まない)
tools/       開発用ツール (ALD/QNT 処理・アンカー抽出・アップスケール等)
docs/        CG 素材の用途対応表・実装仕様メモ
```

### 仕組み

- **AIN パッチ**: `alice-tools` で逆アセンブル → 「関数名+命令文脈」のアンカーで座標定数を照合 → 即値を2倍に書き換え → 再暗号化。固定オフセットではないため、他パッチで関数が書き換わっていても適用できます
- **ALD パッチ**: アーカイブをストリーミング再構築し、HD 素材を名前ベースで差し替え。エントリ順とリンクテーブルは保持されます
- **アセット生成**: 詳細な画像は AI アップスケール (ForgeNeo / 2x-AnimeSharpV4)、マスク・ラベル・黒塗り素材はニアレスト2倍化。QNT のアルファチャンネルとオフセットは保持
